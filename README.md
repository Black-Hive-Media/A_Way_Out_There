## Unity 6 Game using C# in Visual Studio

### What This Game Does Currently
Space exploration game where players manage their thrusters, glide through the universe and pick up space junk. Once their inventory is full, they can navigate back to their dock and sell items in the managed store.

### Who It's For
Casual gamers who want a chill atmosphere in a sci-fi setting.

### What It's Built With
Unity 6
C# in Visual Studio Code

### How To Run It
** Requires Unity 6 **
Download the project files, navigate to Unity Hub. Click "Add Project From Disk" and navigate to folder containing all files. 

## Features

### Current In Game Features
- movement
- space junk generator
- mining laser and over heat logic
- retractor beam to pull in objects aboard space ship
- inventory
- docking logic

### Future Features
- managed store to upgrade ship (thrusters, retractor beam, mining laser, visual customization, long range hyper-drive)
- game progression for higher tier space junk
- two-player couch co-op mode in same ship with controls for second player's laser-net to pull in their own smaller findings on the quick
- procedually generated space debris based on solar system 
- multi-player online/local for trading commodities, exploring other players' inventor with docked with eachother(ship-to-ship docking request system)
- Market trading at Space Ports for minerals, food/drink, medical supplies, and tech items
