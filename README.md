## Unity 6 Game using C# in Visual Studio

### What This Game Does
Space exploration game where players manage their thrusters, glide through the universe and pick up space junk. Once their inventory is full, they can navigate back to their dock and sell items.

### Who It's For
Casual gamers who want a chill atmosphere in a sci-fi setting.

### What It's Built With
Unity 6
C# in Visual Studio Code

### How To Run It
** Requires Unity 6 **
Download the project files, navigate to Unity Hub. Click "Add Project From Disk" and navigate to folder containing all files. 

## Features

### In Game Features
- movement
- space junk generator
- mining laser and over heat logic
- retractor beam to pull in objects aboard space ship
- inventory
- docking logic

### Future Features
- store to upgrade ship thrusters, retractor beam, and mining laser
- game progression for higher tier space junk
- two-player couch co-op mode
